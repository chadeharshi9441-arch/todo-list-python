# To-Do List App

A simple console-based To-Do List application built in Python.

## Features
- Add tasks
- View all tasks
- Delete tasks
- Menu-driven interface using loops and conditionals

## How to Run
1. Make sure Python is installed
2. Run the file: `python todo.py`
3. Follow the on-screen menu to manage your tasks

## What I Learned
This was my first Python project, where I practiced using lists, loops, and conditional statements to build an interactive program.
